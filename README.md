# Дворец без рассвета

Публичный репозиторий сборок и отдельного AltStore Classic source. Исходники приватные. Релизные файлы первой проверенной версии подготавливаются.

Первый прототип: катана и молния, рывок, японская арена, два вида демонов и босс с предупреждаемыми атаками. Графика временная, собственная. Версия0.1.0/build1; checkpoint v0.1.0-prototype.1.

Unity Play Mode:26 PASS; Unity iOS-export и Xcode device build прошли. Приложение требует переподписи AltStore. На физическом устройстве и в AltStore установка не проверена. Платежей, аккаунтов, серверов и сохранения нового прогресса нет.

Другие приложения/источники не изменяются. Здесь нет исходников, личных сейвов, секретов, provisioning и внутренних логов.
